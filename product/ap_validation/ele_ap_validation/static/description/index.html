Vendor Bill Validation Workflow

Add a real approval step before a vendor bill counts as accepted, without touching how Odoo posts it.

The problem

Odoo's own bill states (Draft, Posted, Cancelled) describe accounting status, not whether anyone has actually agreed the bill is correct and should be paid. Without a separate approval step, a bill can be posted — and scheduled for payment — before anyone with the authority to catch a mistake has looked at it.

What this app does

It adds an approval status to vendor bills, tracked independently of the accounting state:

Draft → Awaiting Validation → Validated

A bill can be routed one of two ways:

  • Management — schedules an activity for a member of the configured approver group, so the right person is notified rather than relying on someone remembering to check.
  • Operations — raises an expense record from the bill; approving that expense validates the bill in turn, so the approval happens inside the workflow your operations team already uses.

Rejecting a bill requires a reason, captured directly on the bill's own chatter — so the "why" behind a rejection is never lost to a side conversation.

Configurable, not hardcoded

Found under Accounting → Configuration → Settings → Vendor Bills: which group of users is allowed to validate a bill. Leave it unset and it falls back to your existing Administration / Settings access group, so an existing database behaves the same until you configure it.

Why it's safe to install

  • Depends only on Odoo's Accounting and Expenses apps — both Community, no Enterprise required.
  • Adds a parallel approval status. It does not change how Odoo itself posts, validates, or pays a bill.
  • No freight, manufacturing, or budgeting dependency — usable by any client on any chart of accounts.
